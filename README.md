# 🐱 QQ 表情包自动化迁移至微信（源码版）

本项目包含两个 Python 核心脚本，用于将 **QQ 电脑版（NT 架构）的自定义表情**无损提取、转码并全自动批量导入至 **微信电脑版**：

1. **`get.py`**：扫描 QQ 表情缓存，识别图片真实类型，将动图与静态图纯净归档；同时将静态图转换为单帧 GIF 并规避尺寸限制，输出微信专用包。
2. **`input.py`**：基于 `pyautogui` 的 RPA 自动化录入流水线，在微信“文件传输助手”中模拟真实鼠标操作完成批量收录。

---

## 🛠️ 环境准备与依赖安装

* **操作系统**：Windows 10 / Windows 11
* **Python 版本**：Python 3.8 及以上
* **必要第三方库**：
  在终端（Terminal）或命令行中执行：
  ```bash
  pip install pillow pyautogui
  ```

---

## 📁 目录结构

运行前后，项目根目录结构如下：

```text
表情包迁移/
│
├── get.py                  # 第一步：提取、还原真实后缀、转码
├── input.py                # 第二步：自动化模拟录入微信
│
├── 表情包/                  # [运行 get.py 自动生成] 原始格式归档 (.gif/.png/.jpg)
└── 微信表情包/               # [运行 get.py 自动生成] 100% 纯 GIF，供 input.py 读取
```

## 🚀 详细运行步骤

### 第一步：配置并运行 `get.py`（提取与转码）

#### 1. 确认 QQ 表情源路径
* 打开电脑端 QQ -> 点击左下角 **三（设置）** -> **存储管理** -> **打开文件夹**。
* 依次进入子目录：`nt_qq\nt_data\Emoji\personal_emoji\Ori`。
* 点击资源管理器地址栏，复制这个完整绝对路径。

#### 2. 修改脚本配置
打开 `get.py`，确认第 8 行附近的 `SOURCE_DIR` 为你刚才复制的路径（注意字符串前加 `r` 避免反斜杠转义）：

```python
SOURCE_DIR = Path(
    r"C:\Users\你的用户名\Documents\Tencent Files\你的QQ号\nt_qq\nt_data\Emoji\personal_emoji\Ori"
)
```

#### 3. 执行提取脚本
在 IDE（如 PyCharm）中直接运行 `get.py`，或在命令行运行：
```bash
python get.py
```
* **控制台输出**：程序会依次识别出每个文件的真实二进制头，输出处理进度。
* **生成文件**：
  * **`表情包/`**：存放原始文件（动图还原为 `.gif`，静态图还原为 `.png`/`.jpg`）。
  * **`微信表情包/`**：存放统一格式的 `.gif` 文件（长宽限制在 500px 内，避免微信判定为普通大图）。

---

### 第二步：运行 `input.py`（自动化导入微信）

> ⚠️ **运行前核心警告**：
> 脚本开始全自动循环后，**请绝对不要触碰鼠标和键盘**！否则会导致坐标错位误点。

#### 1. 准备微信窗口
* 登录电脑版微信，打开 **【文件传输助手】** 的聊天界面。
* 确保微信窗口停留在屏幕主可视区域，不要最小化。

#### 2. 执行导入脚本
在 IDE 中直接运行 `input.py`，或在命令行运行：
```bash
python input.py
```

#### 3. 配合控制台的两次倒计时校准
脚本启动后，需要进行一次精准的鼠标位置校准（仅需几秒）：

* **第 1 次倒计时（5 秒）**：
  * 立刻把鼠标指针移动到微信 **【输入文字的空白区域】**，停住不要动。
  * 倒计时结束时，脚本自动记录输入框坐标，并发出第 1 张测试表情。
* **第 2 次倒计时（6 秒）**：
  * 用鼠标**右键点击刚才发出的那张测试图**。
  * 在弹出的右键菜单中，**把鼠标光标悬停在绿色的【添加到表情】这一行上，停住不要动**。
  * 倒计时结束时，脚本会自动点击收录第 1 张表情，并完成菜单坐标校准。

#### 4. 全自动流水线执行
* 校准完成后，脚本会有 3 秒缓冲提示，随后自动接管鼠标：
  * 流程：`放入剪贴板 -> 粘贴发送 -> 等待渲染 -> 自动右键 -> 点击添加到表情 -> 下一张`。
* 67 个表情大约在 **1.5 ~ 2 分钟** 内全量录入完毕。

---

## 🛑 紧急停止机制（防止失控）

在 `input.py` 运行期间，如果遇到点歪、卡顿或需要中途退出，有两种叫停方式：

1. **物理鼠标甩角（PyAutoGUI FAILSAFE）**：
   * 用手抓住鼠标，**快速用力将鼠标光标推到屏幕的最左上角（像素坐标 0, 0）**。
   * 脚本捕获到底层异常后会立刻触发紧急制动强行退出，不会在桌面乱点。
2. **终端中断信号**：
   * 在 PyCharm / VS Code 中按快捷键 **`Ctrl + F2`**（或点击红色正方形 Stop 按钮）。
   * 命令行窗口中按下 **`Ctrl + C`**。

---

## 📱 最终同步与查收

1. 待 `input.py` 控制台输出 `🏁 全部表情处理完毕！` 后即可恢复正常使用电脑。
2. 打开**手机端微信**：
   * 进入任意聊天框 -> 点击表情图标 -> 点击 **爱心 ❤️ 栏**（添加的单个表情）。
   * 稍等数秒等待云端拉取，刚才所有的 QQ 表情包均会完整同步至手机，动图保持原生流畅播放。


# 📖 QQ 表情包导入微信工具（打包版）

> **使用前准备**：
> 1. 新建一个空文件夹（比如命名为 `表情包迁移`），把dist里的两个打包好的程序 **`get.exe`** 和 **`input.exe`** 放进去。
> 2. 电脑上登录好 **QQ** 和 **微信**。

---

### 第一步：提取 QQ 表情包（运行 `get.exe`）

1. **双击运行 `get.exe`**，会弹出一个黑色命令窗口。
2. **如果提示输入路径**：
   * 打开电脑 QQ -> 点击左下角 **三（设置）** -> **存储管理** -> **打开文件夹**。
   * 依次点进文件夹：`nt_qq` -> `nt_data` -> `Emoji` -> `personal_emoji` -> **`Ori`**。
   * 点击窗口顶部的地址栏，**复制完整路径**。
   * 回到黑框中，按鼠标右键（或 `Ctrl + V`）**粘贴路径并敲回车**。
3. 程序会自动开始扫描提取并转码，看到提示“🎉 全部处理完成”后，**敲一下回车退出**。
4. 此时工具旁边会自动生成两个文件夹，**不用动它们**，直接进行第二步。

---

### 第二步：自动录入微信（运行 `input.exe`）

> ⚠️ **全过程最核心注意事项**：
> 程序在全自动运行时会自己移动鼠标，**请不要用手去碰鼠标和键盘**！

1. **准备微信**：
   * 打开电脑版微信，点进 **【文件传输助手】** 的聊天界面，把微信窗口放在屏幕中间显眼位置。
2. **双击运行 `input.exe`**，看着黑框里的文字提示配合**两次倒计时**：
   * **第 1 次倒计时（5 秒）**：
     立刻把鼠标指针移动到微信 **【输入文字的空白区域】** 停住不要动！
     *(倒计时结束后，它会自动发出一张测试图片)*
   * **第 2 次倒计时（6 秒）**：
     用鼠标**右键点击刚才发出的那张测试图**，在弹出的菜单中，**把鼠标悬停在绿色的【添加到表情】上停住不要动**！
     *(倒计时结束后，它会自动点击收录第一张表情并完成校准)*
3. **静等全自动完成**：
   * 校准完毕后，脚本就会开始全自动操作：**发一张 -> 右键收录一张**。
   * 此时你可以把手拿开，大概 1 分钟左右就能全部录完，完成后按回车退出。

---

### 🛑 万一鼠标点歪了，怎么紧急刹车？
如果中途发现鼠标点歪了、或者想强制停止：
👉 **用手抓住鼠标，快速、用力将鼠标猛甩到电脑屏幕的最左上角（坐标 0, 0）**！
程序检测到后会立刻紧急制动强行退出，不会乱点你的电脑。

---

### 第三步：手机端查收
电脑端运行完成后，打开**手机微信**：
* 随便打开一个聊天框 -> 点击表情图标 -> 点击 **爱心 ❤️ 栏**。
* 刷新一下，刚才所有的 QQ 表情包就已经整整齐齐地同步到你的手机里了（动图均正常动态播放）！
